## 📝 Common Syntax

### 1. Headings
```markdown
# Heading 1 (Title)
## Heading 2 (Section)
### Heading 3 (Subsection)
```

### 2. Fenced Codeblocks
Code is enclosed between triple backticks (```` ``` ````) with a language identifier (such as `powershell`, `python`, `sql`):

````markdown
```powershell
Write-Host "Executing script on local computer..."
```
````
