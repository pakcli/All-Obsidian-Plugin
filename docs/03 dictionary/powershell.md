title: "PowerShell"
---


**PowerShell** is an advanced task automation and scripting platform consisting of a command-line shell and object-oriented scripting language developed by Microsoft for your [[computer|computer]].

---

## ⚡ Key Highlights

### 1. Object Pipeline
Unlike traditional shells that pass unstructured plain text, PowerShell passes rich .NET objects between commands.

### 2. Scripts (`.ps1`)
PowerShell scripts are saved with the `.ps1` file extension. In PakCLI Suite, codeblock scripts inside [[obsidian|Obsidian]] [[markdown|Markdown]] notes can be synced directly to disk scripts using **Codeblock Sync**.

### 3. Cross-Platform
Modern PowerShell (`pwsh`) runs on Windows, macOS, and Linux [[computer|computers]].
