A **Tree Diagram** is a visual representation of directory hierarchy, folder trees, and nested file structures on your [[computer|computer]].

---

## 🌳 Asset Router Diagram Generation

PakCLI Suite's **[[asset router|Asset Router]]** module automatically generates dynamic ASCII and SVG directory tree structure diagrams directly inside your [[obsidian|Obsidian]] notes to visualize vault layout and attachment routing.
