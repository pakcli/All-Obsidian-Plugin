**ASCII** (American Standard Code for Information Interchange) is a character encoding standard for plain-text data on your [[computer|computer]].

---

## 🎨 ASCII Art & Diagrams in Obsidian

In [[obsidian|Obsidian]] and software documentation, ASCII is used to render plain-text diagrams, boxed flowcharts, and file hierarchy trees using standard keyboard characters (such as `+`, `-`, `|`, `+--`).

PakCLI Suite's **[[codeblock scaler|Codeblock Scaler]]** module provides intelligent text scaling (`scalefit`) for wide ASCII diagrams to ensure they fit dynamically on screen without clipping.
