---
title: "Clipboard"
---

The system **Clipboard** is an operating system memory buffer used for short-term data storage and transfer between applications via Copy, Cut, and Paste commands (`Ctrl + C` / `Ctrl + V`).

---

## 📋 Asset Draggable Clipboard Integration

PakCLI Suite's **[[asset draggable|Asset Draggable]]** module utilizes the system clipboard to bridge attachments from [[obsidian|Obsidian]] into external desktop apps, web browsers, and AI tools (such as ChatGPT and Claude) with 1-click image copying and native file drag handles.
