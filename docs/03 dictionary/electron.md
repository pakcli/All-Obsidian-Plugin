---
title: "Electron"
---

**Electron** is a software framework that allows developers to build cross-platform desktop applications using web technologies (HTML, CSS, JavaScript, and [[nodejs and typescript|Node.js]]) paired with a [[chromium|Chromium]] rendering engine.

---

## ⚡ Usage in Obsidian

[[obsidian|Obsidian]] is built on top of the Electron framework, allowing [[plugin|plugins]] like PakCLI Suite to interact directly with local filesystem APIs, native shell commands, and hardware acceleration on your [[computer|computer]].
