---
title: "winget"
---

**winget** (Windows Package Manager) is a Microsoft command-line tool that enables users to discover, install, upgrade, remove, and configure applications on Windows 10 and Windows 11 [[computer|computers]].

---

## ⚡ Usage in PakCLI Suite Setup

In PakCLI Suite's automated installation script, `winget` silently installs **[[obsidian|Obsidian]]** (`winget install --id Obsidian.Obsidian`) on new Windows systems before setting up the plugin vault.
