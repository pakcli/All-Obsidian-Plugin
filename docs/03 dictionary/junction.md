---
title: "Directory Junction"
---

A **Directory Junction** (or NTFS Junction Point) is a feature of the Windows filesystem that links one directory location on your [[computer|computer]] transparently to another target folder on disk.

---

## 🔗 Symlink Manager Junction Support

In PakCLI Suite's **[[symlink manager|Symlink Manager]]** module, you can manage both POSIX [[symlink|symbolic links]] and native Windows Directory Junctions without requiring administrative privilege escalation.
