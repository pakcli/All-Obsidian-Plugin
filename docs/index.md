# Introduction to PakCLI Suite

Welcome to **PakCLI Suite** — the all-in-one modular power [[plugin|plugin]] for [[obsidian|Obsidian]]. 

PakCLI Suite supercharges your note-taking environment into an integrated development, data analysis, and media management workspace on your local [[computer|computer]]. Whether you are managing databases with SQL, editing [[csv-and-tsv|CSV and TSV]] spreadsheets, syncing [[powershell|PowerShell]] scripts, or capturing multimedia evidence, PakCLI Suite provides seamless native tools directly inside [[obsidian|Obsidian]] without relying on an [[internet|internet]] connection.

---

| **[[02-sqlseal-and-tablite\|SQLSeal & Tablite]]** | `SQLSeal & Tablite` | Embedded SQLite engine & full virtualized [[csv-and-tsv\|CSV]] table editor | Real-time SQL queries, TanStack virtual grid, cell editing, column freeze |
| **[[03-leaflet-map\|Leaflet Map]]** | `Leaflet Map` | Interactive geospatial and custom world maps | Coordinates, pins, GeoJSON layers, multi-layer map rendering |

| **[[05-yt-extension\|YT Extension]]** | `YT Extension` | YouTube video timestamp capture & evidence clipping | High-resolution frame capture, video segment looping, subtitle sync |
| **[[06-asset-router\|Asset Router]]** | `Asset Router` | Smart attachment routing & file tree diagrams | Centralized folder routing, dynamic tree diagrams, custom folder rules |
| **[[07-symlink-manager\|Symlink Manager]]** | `Symlink Manager` | Filesystem [[symlink\|symbolic links]] & folder junction management | Native directory [[symlink\|symlinks]], link badges, path resolution |
| **[[08-codeblock-scaler\|Codeblock Scaler]]** | `Codeblock Mode` | Intelligent codeblock text scaler and formatter | ASCII diagram auto-fit (`scalefit`), word wrap, and horizontal scrolling |

## 🎯 Why PakCLI Suite?

1. **All-in-One Efficiency**: Replace 8+ separate [[plugin|plugins]] with a single, highly optimized, memory-efficient bundle built with [[nodejs-and-typescript|TypeScript]].
2. **Local-First & Offline**: All operations run locally on your [[computer|computer]] without external cloud dependencies.
3. **High Performance**: Built with virtualized DOM rendering and lazy initialization so your [[obsidian|Obsidian]] vault stays ultra-fast.
4. **[[community|Community]]-Driven**: Designed following Obsidian [[community|community]] best practices.
