# Dictionary: Node.js & TypeScript

**[[nodejs-and-typescript|Node.js & TypeScript]]** form the technological foundation for developing modern [[obsidian|Obsidian]] [[plugin|plugins]] like PakCLI Suite.

---

## 🚀 Key Terms

### 1. Node.js
An open-source JavaScript runtime environment executing code outside of web browsers directly on your local [[computer|computer]].

### 2. TypeScript
A strongly-typed programming language developed by Microsoft that builds on JavaScript by adding static type definitions, ensuring safe and reliable [[plugin|plugin]] execution.

### 3. esbuild
A high-performance bundler that compiles TypeScript source files into a unified `main.js` bundle for distribution to the [[community|community]].
