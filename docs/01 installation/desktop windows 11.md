# Desktop Installation: Windows 11

Installation guide for **Windows 11** desktop PCs and laptops.

---

## 🛠️ Method 1: Community Plugin Market

1. Launch **[[obsidian|Obsidian]]** on Windows 11.
2. Open **Settings** (`Ctrl + ,`).
3. Navigate to **[[community|Community]] [[plugin|plugins]]** and disable **Restricted mode**.
4. Click **Browse**, search for `PakCLI Suite`, then click **Install** and **Enable**.

---

## 📦 Method 2: Manual File Explorer Installation

1. Open File Explorer (`Win + E`) to your vault path:
   ```text
   C:\Users\<Username>\Documents\ObsidianVault\.obsidian\plugins\pakcli-suite\
   ```
2. Copy `main.js`, `manifest.json`, and `styles.css` into the `pakcli-suite` directory.
3. Reload plugins in **Settings -> [[community|Community]] [[plugin|plugins]]** and enable **PakCLI Suite**.
