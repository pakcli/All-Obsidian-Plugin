# Desktop Installation: Linux

Installation guide for **Linux** desktop distributions (Ubuntu, Fedora, Arch Linux, Debian, etc.).

---

## 🛠️ Method 1: Community Plugin Market

1. Launch **[[obsidian|Obsidian]]** on Linux.
2. Open **Settings** (`Ctrl + ,`).
3. Select **[[community|Community]] [[plugin|plugins]]** and turn off **Restricted mode**.
4. Click **Browse**, search for `PakCLI Suite`, then click **Install** and **Enable**.

---

## 📦 Method 2: Manual Terminal Installation

```bash
cd "$HOME/Documents/ObsidianVault/.obsidian/plugins/"
mkdir -p pakcli-suite
cd pakcli-suite
# Copy main.js and manifest.json into this folder
```
