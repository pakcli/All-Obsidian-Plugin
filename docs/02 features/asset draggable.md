# Feature: Asset Draggable (AI Drag & Drop Bridge)

**Asset Draggable** allows you to seamlessly drag and drop local images and attachments from [[obsidian|Obsidian]] directly into external browser applications (such as ChatGPT, Claude, Discord, and Slack) without opening [[computer|File Explorer]].

---

## 🖱️ Key Capabilities

- **Native Drag Out of Obsidian**: Click and drag any embedded image from your [[obsidian|Obsidian]] note directly into your browser tab or desktop application via [[native image drag and drop|native image drag-and-drop]].
- **Copy Image Data to Clipboard**: Right-click any embedded image and select **Copy Image (Binary)** to paste directly into AI chatbots using [[one click clipboard image copying|1-click clipboard image copying]].
- **File Path Resolution**: Automatically performs [[path resolution|file path resolution]] to map vault-relative paths (`![[image.png]]`) to absolute local filesystem paths on your [[computer|computer]].

---

## 🚀 How to Use

1. Place your cursor or mouse over any embedded image in Reading or Live Preview mode inside [[obsidian|Obsidian]].
2. Drag the image directly into your browser window (e.g. ChatGPT or Claude input box).
3. The image is instantly attached and ready to prompt!

---

## ⚙️ Configuration (Settings → PakCLI Suite → Asset Draggable)

- **Enable Drag-Out Helper**: Toggle native dragging bridge on or off.
- **Right-Click Context Menu Options**: Enable **Copy Absolute Path** and **Copy Image Binary** to your [[clipboard|clipboard]] in note context menus.
