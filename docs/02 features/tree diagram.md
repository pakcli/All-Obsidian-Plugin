# Feature: Tree Diagram

**Tree Diagram** automatically generates visual [[ascii|ASCII]], Mermaid, and SVG [[tree diagram|tree structure diagrams]] of any folder or note directory hierarchy in your [[obsidian|vault]].

---

## 🌲 Key Capabilities

### 1. Interactive File Tree Generator
- Generate visual [[ascii|ASCII]] and SVG [[dynamic tree diagrams|tree diagrams]] of any directory structure in your [[obsidian|vault]]:

```text
├── Digital Library/
│   ├── CLI & Commands/
│   │   ├── Command Prompt/
│   │   ├── Gitbash/
│   │   └── [[powershell|Powershell]]/
│   └── Research/
└── ALL SCRIPT/
```

### 2. Customizable Diagram Styles
- Format tree outputs as plain [[ascii|ASCII]] text, fenced Markdown codeblocks, or rich SVG graphics.
- Copy tree outputs directly to your [[clipboard|clipboard]] or embed them in notes.

---

## ⚙️ Configuration (Settings → PakCLI Suite → Tree Diagram)

- **Default Diagram Style**: Select default output format (`ASCII`, `Mermaid`, or `SVG`).
- **Max Depth Level**: Configure how deep the folder tree scanner traverses.
- **Ignore Hidden Files**: Skip hidden folders (e.g. `.obsidian`, `.git`) during tree generation.
