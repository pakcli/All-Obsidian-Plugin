# Feature: Date Picker

**Date Picker** provides a fast, keyboard-friendly date selector and natural language timestamp inserter.

---

## 📅 Key Capabilities

- **Interactive Calendar Modal**: Open a visual mini calendar to pick any date with one click.
- **Natural Language Parsing**: Type terms like `today`, `tomorrow`, `next friday`, or `+3d` to automatically resolve the date.
- **Custom Format Presets**: Output dates in standard formats such as `YYYY-MM-DD`, `DD/MM/YYYY`, or timestamped formats (`YYYY-MM-DD HH:mm`).
- **Wikilink Daily Notes Integration**: Optionally wrap inserted dates as daily note wikilinks (`[[2026-08-16]]`).

---

## ⌨️ Shortcuts & Commands

- Open Command Palette (`Ctrl + P`): `Date Picker: Insert current date` or `Date Picker: Open calendar popup`.
- Custom hotkey can be bound via **Settings → Hotkeys**.

---

## ⚙️ Configuration (Settings → PakCLI Suite → Date Picker)

- **Default Date Format**: Set your preferred date pattern (e.g. `YYYY-MM-DD`).
- **Wrap with Wikilinks**: Automatically wrap inserted dates with `[[...]]`.
- **Include Timestamp**: Append current local time (`HH:mm:ss`).
